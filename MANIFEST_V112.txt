DOCUMENT WORKFLOW
- draft -> approved -> posted
- draft/approved -> cancelled
- posted documents cannot be edited/deleted directly
- posting can create a real core Transaction and JournalEntry and link their IDs back to the V112 document
- existing AccountingPeriod is respected when the period is already closed
- all V112 document actions are written to existing AuditLog

IMPORTANT
This V112 layer provides a real shared persistence/workflow foundation for accounting domains that did not have dedicated models. It is not a claim of literal one-to-one parity with every MISA product, integration, licensed tax/e-invoice service or industry-specific workflow. Specialized tables and regulatory integrations can replace the shared document layer incrementally without breaking the V112 contract.
